## 第 2 段：开通免费的云开发环境（第一部分 二）

> 这一步是在腾讯云上"租"一块免费的地方，放我们的程序和数据库。

> 2. 点「新建环境」，会新开一个标签页，看到几张套餐卡片（免费体验版 / 个人版 / 标准版 / 企业版）。
> 3. 按下面填：
>    - **地域**：选「上海」（不要选新加坡，新加坡的不支持我们要用的组合）
>    - **环境名称**：填 `<环境名称>`（只能用小写英文字母、数字和减号，字母开头）
>    - **套餐**：选「免费体验版」，**看到"免费试用 6 个月"算对**
>    - **数据库**：选「PostgreSQL 数据库」（一般默认就是它）。**这个以后改不了**，请确认选中的是 PostgreSQL。
> 4. **兑换码**：鼠标移到兑换码输入框下面的"关注公众号"字样，会弹出一个二维码。用手机微信扫码关注这个公众号，在公众号对话框里发送四个字"领取兑换码"，它会回你一串码。把这串码复制、粘贴到兑换码输入框里。**输入框不再是红色算对。**
> 5. 确认页面上的总金额是 **¥0.00**，点「立即购买」。
> 6. 进入"确认订单"页后，**往下拉到底部的"搭配购买"，里面的东西一个都不要勾**（那些都另外收钱），然后点「去支付」。**看到"支付成功"算对。**
> 7. 回到 https://tcb.cloud.tencent.com/dev ，**环境列表里出现 `<环境名称>` 开头的新环境，状态"正常"、套餐"体验版"算对。**截图发我。

## 第 3 段：打开"云托管"开关（第一部分 三）

> "云托管"就是让我们的程序在云上跑起来的那个功能，默认是关着的，需要你手动打开一次。
>
> 1. 在云开发控制台（https://tcb.cloud.tencent.com/dev ，点进刚建好的环境）左侧菜单找「云函数 / 托管」，点它。
> 2. 中间那一栏找到「云托管」下面的「服务管理」，点它。**注意：不要点"创建服务"。**
> 3. 页面底部有一个勾选框"我已知晓《腾讯云云开发服务条款》及云托管付费模式"，勾上，再点「启用云托管」。
>    （"付费模式"这几个字不用担心：免费体验版下用的是每月送的免费额度，用完就停，不会从你账户扣钱。）
> 4. 会弹出一个"CODING 第三方软件授权声明"，点「同意并继续」。（它说的是"部署别人的软件要有授权"，我们部署的是自己的代码，不涉及。）
> 5. **看到"服务列表"、里面写着暂无服务，算对。**截图发我。

## 第 4 段：生成"服务端钥匙"并自己粘贴进文件（第一部分 四）

> 我们的程序读写数据库需要一把钥匙（叫"服务端 API Key"）。**这把钥匙很重要：谁拿到它就能读写你所有的数据，所以请不要把它发到对话里，也不要截图给我。**你只要按下面的步骤把它粘贴到我准备好的文件里，然后跟我说"填好了"就行。
>
> 我已经在你电脑上建好了这个文件，并确认它不会被上传到任何地方：
> `工具包文件夹 / projects / 小红书标题助手 / backend / .env`
>
> 1. 在云开发控制台左下角找「环境管理」，点开后选「API Key 配置」。
> 2. 页面上有两块：上面是"客户端 Publishable Key"，**下面才是"服务端 API Key"**。在**下面这块**点「创建 API Key」。弹出"创建 API Key"窗口算对。
> 3. 名称填 `xhs-title-backend`（用英文就行）；过期时间选 **180 天**。
> 4. 点「创建」。会弹出一长串字符（很长，几百个字母），**它通常只显示这一次**。点旁边的复制按钮复制它。**先不要关这个弹窗。**
> 5. 打开"访达（Finder）"，进到上面那个 `backend` 文件夹。`.env` 是"隐藏文件"，默认看不到：在键盘上同时按 **Command + Shift + 句号（.）**，它就会显示出来（再按一次又藏起来）。
> 6. 在 `.env` 上**点右键 →「打开方式」→「文本编辑」**（不要直接双击，双击可能打不开）。
> 7. 找到写着 `CLOUDBASE_API_KEY=` 的那一行，把光标放到等号**后面**，粘贴（Command + V）。等号和钥匙之间**不要有空格、不要加引号**，钥匙要在同一行里。
> 8. 按 Command + S 保存，关掉文本编辑。
> 9. 回到对话，只回复三个字："**填好了**"。我会检查长度对不对（我不会把内容打出来）。
>
> 这把钥匙 180 天后过期。到期前两周我会提醒你按同样的步骤再建一把新的替换。

## 第 6 段：费用确认（发在部署之前）

> 部署前跟你确认一下钱的事（以腾讯云页面当时显示为准）：
>
> - **这次上线 0 元**。云开发用的是"免费体验版"：每月送 3000 个"资源点"，**用完就自动停，不会欠费，也不会从你账户扣钱**。6 个月到期前一个月可以免费续 6 个月。
> - 我会把程序设成最小规格（0.25 核 / 0.5 GB）、**没人用时自动睡觉**，只有有人在用才消耗资源点（大约 30 点/小时）。2 个人试用，我估计每月用 900～1800 点，在免费额度以内。用量统计会晚 1～2 天，我会帮你盯着。
> - **模型费用**在 DeepSeek 那边单独扣（不占资源点）：生成一次大约 0.001～0.002 元。我给每人每天设了最多 **50 次**的上限，防止邀请码泄露后被人刷，按这个上限算每月也就几元，在你定的每月 30 元以内。
> - 代价：**第一次打开网址可能要等 5～10 秒**（程序在"起床"）。想要秒开就得让它一直醒着，会持续消耗资源点、免费额度可能不够一个月，所以先不开。
> - 以后如果免费额度不够用，需要升级"个人版"（19.9 元/月，限时价），**到时候我会先告诉你金额，你回复"确认"我才动**。
>
> 如果同意，请回复"**确认**"（或者"按推荐"）。
