## 第 4 段：打开"云托管"开关（第一部分 四；复用环境时跳过）

## 第 5 段：生成"服务端钥匙"，点一下复制（第一部分 五）

> 我们的程序读写数据库需要一把钥匙（叫"服务端 API Key"）。**这把钥匙很重要：谁拿到它就能读写你的数据，所以请不要把它发到对话里，也不要截图给我。**你只要复制它，我会直接从你电脑的剪贴板把它放进一个不会上传到任何地方的文件里，全程不显示内容。
>
> 1. 在云开发控制台左下角找「环境管理」，点开后选「API Key 配置」。
> 2. 页面上有两块：上面是"客户端 Publishable Key"，**下面才是"服务端 API Key"**。在**下面这块**点「创建 API Key」。弹出"创建 API Key"窗口算对。
> 3. 名称填 `<英文短名>-backend`（我会告诉你填什么）；过期时间选 **180 天**。
> 4. 点「创建」。会弹出一长串字符，**它通常只显示这一次**。点旁边的「复制」按钮。**先不要关这个弹窗。**
> 5. 回到对话，只回复四个字："**复制好了**"。**不要粘贴。**
> 6. 我会回复你"已写入，长度 xxx"，这时就可以关掉弹窗了。如果我说"不像一把钥匙"，就回弹窗再点一次「复制」。
>
> 万一不小心把钥匙粘贴进了对话：没关系，告诉我，我们在控制台把这把删掉、重新建一把就行。
>
> 这把钥匙 180 天后过期。到期前两周我会提醒你按同样的步骤再建一把新的替换。
