## ✨ 这是什么

一套给**不懂代码的产品经理 / 学生**的开箱工具包。把它交给一个能操作你电脑的编码 AI（Claude Code、Cursor、Codex 等），贴一句启动句，AI 就带你从"一个想法"走到"上线产品"——写代码、跑测试、做界面、部署上线，全由 AI 完成；你只做少量"必须本人才能做"的事。

> **适用范围**：做 MVP，上线给小范围用户试用。默认用火山引擎分配的网址，不需要自己的域名，也就不用办 ICP 备案；要对公众正式运营（自有域名、公开推广、收费）还需另办备案手续，不在本工具包范围内。
>
> **上线能走多远，取决于云平台认证**：个人实名认证可以长期上线，适合同时在线几十人以内（单实例、不能扩容）；企业实名认证可以随用户量扩容。学生和个人按前者预期，AI 会在阶段 0 问你一次并记下来。
>
> **只支持 Mac 电脑**，Windows 暂不支持。

## 🎯 它解决什么问题

## 🚀 快速开始（约 1 分钟）

1. 把整个文件夹放到你电脑上（压缩包先解压，**不要改里面文件**）。
2. 用一个**能读写文件、执行命令的编码 AI 工具**打开这个文件夹（网页版纯聊天 AI 不行）。
3. 在对话框贴这句话：

   ```text
   请读取项目根目录的 AGENTS.md，按其中"启动流程"开始。
   ```

4. AI 会根据你的情况自动走流程（有没有 PRD、是不是接着上次做）。之后每一步 AI 都会告诉你"下一步做什么"；看不懂就说"用产品语言再说一遍"。

> 📖 完整操作手册见 [开始看这里.md](./开始看这里.md)。

## 🧭 六个阶段

| 阶段 | 内容 | 你要做的 | 通过条件 |
| --- | --- | --- | --- |
| 0 PRD 体检 | 检查 / 补全产品需求 | 回答问题（≤5 个/轮，可回"按推荐"） | 补全清单全部关闭 |
| 1 技术适配 | 定技术方案 | 确认理解对不对、有无多出费用/范围 | 决策台账无影响本阶段的待定项 |
| 2 后端 MVP | 核心能力 + 真实验证 | 提供 Key、给真实结果打分、照清单验收 | 证据包已交 + 闸门全"是" |
| 3 正式前端 | 界面 + 移动端 | 给视觉方向、看代表页、真机走一遍 | 同上 |
| 4 上线 | 部署到云 | 注册/认证、控制台照着点、验收 | 验收清单全过 |
| 5 收尾 | 整理 + 收回部署权限 | 删掉部署用的云密钥（线上运行用的保留） | 状态文件记录完成 |

每个阶段结束，AI 必须交**证据包**（截图 + 可打开地址/照着点步骤 + 是否表 + `verify.sh` 自检输出）。是否表有"否"就不能说完成。

其中测试、密钥、数据恢复、前端构建这四项由根目录的 `verify.sh` 脚本判断，不由 AI 口头申报。你在终端敲 `./verify.sh 阶段N`，看四行大白话结果即可。

## 🔒 内置的强制底线

这套规则卡约束 AI，你可以放心：

- 🔑 密钥不进仓库、不进前端、不回显
- 💾 数据可恢复，重启不丢
- ✅ 真实模型验证，不拿 mock 结果冒充
- 💰 涉及花钱的云资源，先告知费用再动手
- 🔐 用户只能看自己的数据
- 🛡️ 错误不泄露技术堆栈

## 📦 环境要求

- 一台 Mac 电脑
- 一个编码 AI 工具：推荐 Claude Code、Codex 或 [Pi](https://pi.dev/)；其他能读写文件、执行命令的工具也可以。规则写在 `AGENTS.md` 里，不绑定某个工具或模型；工具里接 DeepSeek 等国内模型也行
- Python 3.12、Node.js（当前长期支持版）、Git（开发时 AI 会检查，缺了给"照着装"步骤）
- 一个模型 API Key（开发期可后补，验收前必须有）

## ❓ 常见问题

**要花钱吗？** 两处：模型 Key（按用量付费，AI 会帮你估）；上线云费用（上线前会估，创建前必须经你确认）。开发期可先不买 Key，AI 用模拟数据推进。

**必须企业认证吗？** 不必须。个人认证走过渡档，可以长期使用，限制是只能一个实例、不能扩容，适合同时在线几十人以内。数据写入后约几秒内备份到云端，服务意外重启最多丢最后几秒的写入；AI 每月提醒你导出一次备份。以后办下企业认证可以切换，不是必须。

**AI 说做完了，我怎么信？** 看证据包：截图 + 可打开的地址 + 是否表。有"否"就不算完成。

**可以中途换模型 / 换工具吗？** 可以。规则和进度都存在文件夹里（`docs/项目状态.md`），不依赖某个模型的内存。
